# Matriz de aceptación

La matriz sigue las secciones 4 a 10 del enunciado original. [PDF de la prueba](../PruebaTecnica_Productos_UPC.pdf) **Cumplido** indica que el comportamiento solicitado existe. **Adaptado** indica que el objetivo se cumple con el mecanismo distinto y justificado que se describe. La [auditoría final](../ia/planes/08-auditoria-final.md) y la [regresión de QA](../ia/planes/10-correcciones-qa.md) registran las ejecuciones verificadas.

## Adaptaciones adicionales del enunciado

| Referencia                        | Decisión                                                                                                                                                                                                  |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| HU-01, nota de UPC numérico       | `varchar(12)` preserva ceros iniciales y permite una restricción única.                                                                                                                                   |
| HU-02, fechas recibidas           | La API devuelve UTC ISO 8601 a segundos. Calcula las fechas de escritura y conserva la auditoría histórica importada.                                                                                     |
| HU-02, §9, borrado por GET        | Se usa DELETE, con 204 y sin cuerpo, para evitar efectos de escritura en una lectura.                                                                                                                     |
| HU-03, §7 y DoD                   | JWT con vigencia predeterminada de una hora, secreto exclusivo de Nest y contraseñas hasheadas con Argon2id. Las peticiones web son del mismo origen y los orígenes ajenos se rechazan en las mutaciones. |
| README, §10, versionar `.env`     | Se publica `.env.example`; el secreto se genera localmente. Las cuentas demo aparecen separadas y corresponden al enunciado.                                                                              |
| Entrega pública y defensa, §10–11 | Pendientes de la aprobación y gestión del candidato. El historial existente es incremental.                                                                                                               |
